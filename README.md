# Donnerfausts Vineyard

Verwaltungs- und Handelssystem für Donnerfausts Vineyard.

## Bereiche
- Dashboard
- Lagerbestand und Lagerbewegungen
- Kasse
- Mitarbeiter und Rollen
- Audit-Protokoll

Die Anwendung verwendet Supabase Auth und eine rollenbasierte Datenbankstruktur. Sensible Admin-Schlüssel werden nicht im Browser veröffentlicht.

Dieses Projekt ist für die interne RP-Verwaltung bestimmt.
